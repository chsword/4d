① 先把同一件事在低一维做一遍

人对四维没有直觉，对三维有。所以先看「立方体穿过一张平面，平面上的人看到什么」， 再把每个词加一维搬到四维。这是本项目的教学设计，尚无用户实验验证效果，也不声称是唯一有效的路径。

看 B 面板：平面人看到的多边形边数会从 3 跳到 4、5、6 再跳回去。 他会说「这个东西在变形」，但其实立方体什么都没变，只是它和平面的交在换位置。

② 投影法：4D → 3D → 2D

这里采用两级投影，把全体顶点和棱映到屏幕上；重影和交叉可能掩盖原拓扑， 一般不保长度或角度。超立方体那 8 个立方体胞其实全等，透视图上却大小悬殊。 极点附近的分母钳制和长棱剔除还会省略或改变部分投影。

2.60
六个旋转平面的角速度
三维旋转有不动轴；四维简单旋转固定一个平面。 双旋转的两个平面转角都不是整周时，没有非零固定向量；原点始终固定。 四个轴两两组合出 6 个平面，所以 4D 旋转有 6 个自由度（3D 只有 3 个）。

xy / xz / yz 是我们看得见的那三个「普通」旋转。 xw / yw / zw 混合 w 与可见坐标；sin θ≠0 时不再保持每个点的 w。 投影可能改变，但旋转对称的物体不保证有形变的视觉效果。

等倾双旋转保留当前姿态，再施加 xy 和 zw 同速的增量。 非整周增量没有非零固定向量；每个非零向量都转过相同角度，原点不动。

鼠标拖动 = 转第二级的三维相机；滚轮 = 缩放。

          初始 B 与圆盘内部只在 v=π 的 (0,0,0) 横截一次，z 导数为 −1，

不相交闭曲线的 Gauss 映射 (A−B)/|A−B| : S¹×S¹→S²
          在连续三维运动中始终有定义。按 du∧dv 定向，Lk=−deg(G)，其整数度数不变。
          完全分开的两环 Lk=0，故要从 −1 变成 0 必须先发生中心线相交；
